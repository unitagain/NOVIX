# WenShape 语义检索依赖 / Semantic retrieval dependencies
#
# 默认配置启用“语义 + 词法”混合检索。缺少本依赖时运行时会显式降级为 BM25，
# benchmark 会把该降级视为 strategy fidelity 失败，不允许作为 hybrid 证据。
#
# 用法 / Usage:
#   pip install -r requirements-embeddings.txt
#
# 说明 / Notes:
#   - fastembed 内部带 onnxruntime（纯 CPU，无需 GPU）。
#   - 默认模型 BAAI/bge-small-zh-v1.5（~100MB，512 维）—— 低内存场景下中文检索性价比最优。
#     首次使用自动下载到 config.yaml 的 retrieval.embeddings.cache_dir；
#     离线/桌面打包可预先放置模型文件（见 desktop 打包说明）。
#   - 已纳入 requirements.lock 与 requirements.runtime.txt，确保开发和桌面 sidecar 默认可用。
